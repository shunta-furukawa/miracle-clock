# Miracle Clock 〜ルカと空のとけい便〜

Miracle Mine の続編。完成した蒸気飛行機で、ルカとトトじいが「空のとけい便」を開業します。
魔法の時計「とけいの羅針盤」を合わせ、モス・シェル・クリム・フレア・フウの荷物を浮遊島へ届けるブラウザゲームです。

## 遊び方

1. 配送所の便を選び、受付を始めます。各章は10・15・20・24・27・30人。最初の便は3時×4人、6時×3人、9時×3人です。
2. 注文ボードに待ち客全員の配達時刻と人数を表示。同時刻の注文を選び、時計の針を合わせます。注文選択だけでは針は動きません。
3. 時計の中心を刻印すると、列の順番に関係なく一致した全員をまとめて配達。演出中も次の操作ができます。
4. 成功した刻印ごとにコンボが1増加。不正解はコンボが途切れ、待ち客と時計はそのまま。先頭で時間切れになると1人が帰り、ライフが1減ります。
5. 第2便以降は9人から始まり、3人ずつ来店。列を空にすると次の来客をすぐ迎えます。全員の受付が終われば結果を表示します。

- エンドレスは10人で開始、6秒ごとに3人来店（配達24人ごとに0.4秒短縮、下限1.8秒）。24人満員またはライフ0で終了。ライフは3。
- 1〜4章は午前・午後を問いません。5〜6章は午前・午後も一致が必要。相対時刻の注文もボードには届ける時刻を表示し、詳細で受付時刻と時間差を確認できます。
- ＋／−、針のドラッグ、矢印キーに対応。一時停止とタブ非表示では進行を止めます。
- リザルトには星に加え、最大コンボ・最大同時配達・スコアを表示。章最後もステージ結果でリトライを選んでから章クリア演出へ進めます。
- 配達日誌3冊と従来のクリア記録は端末内に保存。星の最高記録は引き継ぎます。

## ステージ

|章|舞台|学習内容|

|1|こもれびの森|正時|
|2|しおかぜの港|30分・半|
|3|きらめきの洞窟|15分・30分・45分|

相対時刻は注文ごとの受付時刻を固定。午前・午後は針とは別に指定します。
時計の判定は時刻の完全一致です。最初の4章のみ午前・午後を問いません。

## 開発

Node.js 20以上。ゲーム本体は外部依存なしの HTML / CSS / JavaScript。

```sh
npm test
npm run build
npm run dev
```

`http://localhost:4173` で開きます。`dist/` が静的配信用の出力です。
公開URL: https://miracle-clock.vercel.app/

初回は Vercel Drop to Deploy で、画像・CSS・JavaScriptを埋め込んだ静的HTMLを公開しました。`node scripts/pack.mjs` で同じ配信用ファイルを再生成できます。

通常のGit連携用のビルド・出力設定も `vercel.json` に同梱しています。

ブラウザテストは GitHub Actions が Chromium / WebKit で実行し、画面キャプチャを保存します。
ローカルでは `npm install --no-save --package-lock=false playwright@1.58.2` と `npx playwright install chromium webkit` の後に `node tests/browser.mjs`。

## CIと本番デプロイ

GitHub Actions の `Check game` が単体テスト・ビルド・Chromium/WebKitテストを実行します。
既存VercelプロジェクトのGit連携がpushを検知し、`main` は本番、他のブランチはプレビューとして公開します。GitHub側のVercelトークンは不要です。

本番ビルドは `scripts/build-vercel.mjs` が同じコミットのpush起点の `test.yml` 成功を確認してから実行します。未完了は最大15分待機し、失敗・タイムアウト・APIエラー時は公開せずビルドを失敗させます。公開リポジトリのGitHub APIを認証なしで参照するため、APIの利用制限時はVercelから再デプロイしてください。

Actionsの再実行だけでは新しいVercelデプロイは作られません。失敗を修正してmainへpushするか、CI成功後にVercelで同じコミットを再デプロイしてください。

### 章と配達日誌
6章×6ステージ（全36便）を順に遊び、時間とミス回数による三つ星に挑戦できます。通常便は3〜8人のお客さん全員が最初から並び、お届けや帰宅で1人ずつ減ります。独立した練習モードはなく、序盤の簡単な注文で操作を覚えます。第6章はスナリとトビネズミ族の「砂丘の温室」。全ステージクリア後は、トトじいと全種族の注文を受けるエンドレス「空の中央便」が開きます。3つの日誌に進行・最高評価・中央便の最高／累計便数を個別保存します。旧クリア記録は対応する章へ引き継ぎます（旧タイム未記録のため星は再挑戦で獲得）。

## ホーム画面アプリ（PWA）
Safari の共有 → ホーム画面に追加 →「Webアプリとして開く」をオンにして追加。初回にネット接続し、タイトルの「オフラインでもあそべます」を確認すれば、全章の画像・会話・配達演出を通信なしで利用できます。端末の容量整理で保存領域が削除された場合は、再度ネット接続が必要です。セーブは端末・ブラウザ内の記録で、クラウド同期ではありません。

ビルド時に全ローカル素材を列挙し、内容ハッシュで Service Worker の世代を管理。全素材の保存に成功してから利用可能と表示します。新しい版はタイトルの「新しい版であそぶ」から適用でき、プレイ中の自動再読み込みは行いません。直前のキャッシュも1世代残します。`node tests/pwa.mjs` はサーバー停止後の再起動と配達まで確認します。

ダブルタップ拡大は `touch-action: manipulation` で防ぎ、時計のドラッグ操作は従来どおり。ゲームをバックグラウンドにすると通常の受付を一時停止します。

通常便はライフ3で開始。時間切れで先頭が帰りライフを1失います。不正解はコンボが途切れますが、同じ注文へ再挑戦できます。おてつだいはその便のみライフ6。待ち時間は先頭に立ってから計測し、一時停止中は進みません。配送演出中も操作・来客・時計は進みます。

音の設定はタイトル・配送所選択・一時停止から開けます。BGM／効果音は個別ON・OFF、音量を端末に保存。初期状態はOFF。Miracle Mineと共通のPeriTuneの章別楽曲とKenneyの効果音・ジングルを使用し、設定内にクレジットを表示します。画面切替時はクロスフェード、会話／結果／ジングル中はBGMを抑え、バックグラウンドでは停止。音源はPWAのオフラインキャッシュに含めます。出典と加工履歴は docs/audio-sources.json。

行列は受付背景の上に最大8人を描画。全員の注文は時刻別ボードに人数つきで表示します。刻印すると一致した注文をすべて配達し、短い荷物・飛行機の演出が操作を遮らず流れます。

### Title and app updates
The title matches Miracle Mine's illustrated logo / parchment-button layout. It shows `Ver. 0.3.0`, a generated Miracle Clock emblem and a Luca-with-clock app icon. `更新を確認` is always available on the title. It reports download progress, a ready update, the latest version or a retryable connection failure. `新しい版であそぶ` activates a fully downloaded release and reloads without clearing diary data. The build emits a content-based `version.json` and an HTML build identifier. Precache downloads revalidate resources; code, CSS, HTML and manifests are served with revalidation headers.

### 配送所の繁盛と開所準備（0.4.0）

各章は6つの小さな便ボタンで選択します。全36便に開店前の会話があり、来客数とお店の評判が徐々に増えます。選んだ章のBGMは会話・プレイ・結果・配送所選択を通して継続し、別の章を選ぶと切り替わります。

各章の6便をクリアすると、中央配送所へ受付カウンター／荷物棚／案内灯／仕分け機／通信塔／開所看板が届きます。「中央配送所のしたく」で設備と贈り物を見返せます。獲得状態は各配達日誌の既存ステージ記録から算出するため、以前クリアした章にも反映されます。全36便で中央便のエンドレスを開所できます。

### 横画面の受付（0.4.1）

横画面は左に時計、右上に行列、右下に注文と針の操作を配置。吹き出しの上部余白を確保し、開始前の説明を短くしました。飛行演出のスキップ案内は演出内に表示し、背後のメッセージは隠します。

### 時計の操作音とクリア演出（0.4.2）

Kenney Interface Soundsの新しい短音を追加。長い針は5分、短い針は1時間の目盛りを通過するとクリック音と鉱石の光が反応します。逆回し・12時をまたぐ操作にも対応し、同じ目盛り付近の揺れで連打しません。針の選択には独立したスイッチ音を使います。

クリア結果はMineと同じ喜ぶルカ、星と紙吹雪、上昇するクリアジングルを同期。章の贈り物には章クリアのジングルを使用。章BGMは継続したままジングル中に音量を下げます。音量とミュートは既存設定を尊重します。素材の出典・加工内容は `docs/audio-sources.json`。

### 章の到着と配送所づくり
各章の1便目は配送所の風景と章タイトルを表示し、「物語をはじめる」で会話へ進みます。章をまたぐ「次の便へ」でも同じ演出が入り、章内のBGMは継続します。章クリアの贈り物は「取り付ける」で建物の変化を確認できます。「中央配送所のしたく」では3種類の看板紋章を選べ、各配達日誌に独立して保存されます。過去の贈り物の演出も見返せます。

刻印成功時は専用の魔法音（オリジナル合成）と、時計内に収まる二重の魔法陣・36粒の光を再生します。発送までの時間は増やさず、タップで音と演出を終了できます。効果音OFFと動きを減らす設定に対応しています。音の再生成は `python scripts/make-spell-audio.py`（numpy / ffmpeg）。

章頭は全画面の風景と章タイトルで表示します。報酬の設備には専用画像があり、「取り付ける」で店の対応箇所へ飛来し、到着時に外観が変わります。行列は配送所ごとの受付前背景と、受付を向く24人の専用画像を使用します。

0.4.6: Miracle Mineに合わせて章導入の背景ズーム・光・タイトル登場演出を追加。章末は星つきステージ結果を先に表示し、続行または配送所へ戻る選択後に章末会話と報酬を表示します。リトライは演出を挟まず再挑戦でき、再クリア後も報酬演出へ進めます。

0.4.7: 荷札の文字ハンコを、生成した外枠・長針・短針で時刻を示す円形の印影へ変更。紙に着く瞬間に以前の短い押印音を重ねます。

0.4.8: iPadなど高さのある横画面でも時計を左、行列・注文・操作を右に配置。キャラクターのサイド表示を省き、盤面を拡大。受付背景は縦横比を保って切り抜き表示します。

0.4.9: 中央便はライフ3。不正解は同じ注文と待ち時間を維持し、先頭で105秒待つと退場・ライフ減少。ライフ0または行列5人で終了。配達ごとの記録と来客の加速は継続。


0.5.0: 配送ラッシュ。序盤10・15・20人、全員分の時刻別注文ボード、一括配達、コンボ、操作を止めない刻印。後続便は3人ずつ来店。中央便は10人開始・24人満員。
