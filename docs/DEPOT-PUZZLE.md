# 配送所の受付（0.8.0）

36ステージを、時間制限のない時計パズルに置きかえた。0.7の「一日便」は、閉店のない「空の中央便」（エンドレス）にだけ残している。

## なぜ変えたか

0.7で遊んだところ、時計がまだ読めない子どもにとっては、文字盤のマークを集めるアクションゲームになっていた。時計を読まなくても、ピンに針を当てれば遊べてしまう。
つまずいていたのは次の2つだった。

- 短い針と長い針の役割（どちらが「時」で、どちらが「分」か）
- 短い針の位置から「何時台か」を読むこと。特に数字に近いとき、つぎの時刻と読みまちがえる

そこで、じっくり考えるパズルに寄せた。ただ、レッスンらしさを前に出すと嫌われるので、配送所の仕事とお話の形で見せている。

## ルール

- 1ステージは3人のお客さんのお話。送る（針を合わせる）→ 帰ってきた便のおへんじを読む（時計を読む）を交互に6回くり返す。
- 送り手はその章の案内役と住民3人。送り先はほかの5つの島の案内役で、行き先の島の絵をカードの背景に出す。
- 読む問題は、3つの封筒から時刻を選ぶ。お客さんの顔を選択肢にしないのは、時計を読まずに顔で当てられてしまうため。
- 選択肢には、よくある読みまちがいを入れる。つぎの時刻（短い針が数字に近いとき）、数字をそのまま分と読む（6を「6分」）、午前と午後の取りちがえ。
- まちがえると、トトじいがどちらの針がどうずれているかを説明する。2回まちがえるか「トトじいに聞く」を押すと、点線の針で正しい位置を見せる。
- 正解のあと、トトじいが針を1本ずつ読み上げる（「時の針は 8のへや → 8時 / 分の針は 1 → 5分 / だから 8時5分じゃ！」）。
- 星は一回目での正解で決まる（★★★ まちがい・ヒントなし、★★ 2回まで、★ クリア）。
- おかえしは36種類。配達日誌の `gifts` に保存する。まだ持っていない品のお話を先に出す。

## 文字盤

- 12の「へや」を、その数字の宝石の色で塗る。短い針がいるへやを濃くする。へやの番号は、各章の6ステージ目で隠す。
- 短い針には「時」、長い針には「分」のバッジ。真ん中の近くをなぞると短い針、外がわをなぞると長い針が動く。長い針は短い針を連れて回る。
- 合わせている間は「時の針 → 8のへや」「分の針 → 35分」を表示する。読む問題では何も出さない。
- 雲の章では、文字盤に午前・午後の窓を出し、刻印の前に切りかえる。
- 砂丘の章では、点線の針で「いま」を示し、長い針が進んだぶんを金色の帯で見せる。
