# 最初の一便 — 0.10.0

## 意図
ミラクルマインから続く魔法石と絵本の意匠を保つ。時計を合わせる・読む課題に、住人の暮らしに根差した理由と配達の結果を結びつける。

## 世界のルール
鉱山では数を合わせて取り出していた石の力を、配送所では文字盤に並べ、荷札に約束の時間を覚えさせるために使う。配送機は刻印を頼りに運ぶ。受取人の事情は石には分からないので、ルカが依頼を聞いて判断する。受け渡すと荷札には到着時刻が残り、帰着後に台帳へ記録する。

## 範囲
プロローグとステージ1-1だけを改修。残る35ステージとエンドレスは既存の進行。ルカは飛行機を整備するトトじいを手伝い、便りを読んだ後、自分から翌日の受付も続ける。

## 一日の流れ
昼前にモス、カシじい、さくらばあの三件を受付 → 全て刻印して一便出発 → ボタンで夕方6時へ時間を進める → 三通の便りを回答前に自由に読む → 返却された荷札の時刻を台帳に三件記録 → 配達日誌。

| 荷物 | 送り主 → 相手 | 時間の理由 | 到着記録 |
|---|---|---|---|
| 花のたね | モス → シェル | 午後3時台の種まき | 15:15 |
| はちみつ | カシじい → ウズ | 午後4時台の休憩 | 16:20 |
| マフラー | さくらばあ → パールばあ | 午後5時台、灯台に入る前 | 17:40 |

1-1は短針の「何時台」が課題なので、依頼も正時指定ではなく一時間の受取枠。分計算や文章推理を追加しない。会話の全文は「依頼を読む」で参照できる。三択は封筒選びではなく、台帳の記入欄の選択。便りの閲覧を正解の条件にしない。

## 保存
既存v2保存形式に任意のepisodes配列を追加。forest-first-mailの完了時、港の便りを地図から再読可能にする。古いクリア記録から物語既読を推定しない。ステージID、既存の星の最高記録、収集品IDは維持。貝がらは既存IDを使用し重複追加しない。途中退出は従来どおり配達途中の保存なし。

## 検証
依頼と到着時間の整合、三件を預かってから戻り便へ進む順序、旧保存との互換を単体テスト。ブラウザでは針の実操作、回答前の手紙閲覧、小画面での手紙の閉じ方、台帳の誤答と修正、日誌からの再読、再プレイ、新規日誌のステージ解放を検証。既存の通常ステージ・エンドレス・音響・オフラインの検証も継続する。
