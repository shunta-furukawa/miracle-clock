# 一日便（ルール試作）

0.6.0 で本編に採用（0.5 の「ラッシュ」を置き換え）。ルール本体は `src/route.js`、36便とエンドレスの設定は `src/day.js`、プレイ画面は `src/app.js` と `src/day.css`。ルールだけを試せる試作ページ `/prototype/index.html` も残している。

## ねらい

- ラッシュの圧は残す。慌てる中で、文字の時刻と文字盤を反射的に結びつける。
- 圧をかける代わりに、捌けたときの快感をしっかり返す。
- 速く捌く人が損をしない。力技でも届けられ、効率化はその後で考えればよい。
- 午前・午後と「◯時間後」を後付けの変則ルールにせず、最初からゲームの仕組みとして使う。

## 経緯：「針は前にしか進まない」版をやめた理由

最初の試作では、刻印すると「いま」がその時刻に進み、それより前には戻れないルールにした。触ってみると次の問題が出た。

- 時計を進めなければ締め切りが来ないので、列が満員になる直前まで待つのが一番得になる（プレイしない方が得）。
- 一日の長さを自分で使うため、「たくさん届ける」と「早く閉店する」のどちらが正しいのか分からない。
- 早く捌くと、まだ待っている人を巻き込んで乗り遅れにしてしまい、♥を失う。事故のようでやる気が下がる。

根っこは「時間を進める権限をプレイヤーが持っていること」。そこで時間の進行を世界の側に返した。

## ルール（現行）

- 1便＝お店の一日。**「いま」は勝手に進む**（森で1時間10秒ほど）。閉店時刻で営業終了。一日は約2分。
- プレイヤーは長い針を回して「次の便の時刻」を選び、刻印する。**刻印しても時間は進まない。**
- 刻印すると、その時刻の注文を持つ人が、列の位置や書き方（午後2時半／14時30分／2時間半後）に関係なく全員まとめて配達される。
- 注文の時刻が来るまでに刻印できなかった人は**乗り遅れ**。満員の列に来た人は**帰ってしまう**。どちらも取りこぼしとして数えるだけで、♥や途中失敗はない。
- 針は「いま」より後ならどこへでも動かせる（戻るのも自由。ただし長い針を回す手間がかかる）。「いま」が針に追いつくと、針は前へ押し出される。
- 誰もいない時刻に刻印すると、コンボが切れるだけ。
- 来店した人は、実時間で最低数秒先（`lead`）から `horizon` 分先までの時刻を注文する。近い時刻が多く、すでに待っている時刻を別の書き方で頼むことも多い（まとめ便の種）。
- 相対時刻は、来店したときの「いま」を刻み（`step`）に切り下げた時刻が基準。注文票に受付時刻を表示する。
- 星は、その日の来客のうち届けた割合で決める（★★★ 9割、★★ 7割、★ 最後まで営業）。まとめ便の得点は `100n + 50n(n−1)` に、コンボ1回ごとに最大＋90%。

## 表示

- 操作するのは長い針だけ。文字盤のどこをなぞっても長い針が回り、短い針は時刻に合わせてついてくる（一周で1時間）。「時」が変わる瞬間に高い音。大きく進めるときは ±1時間 ボタン。
- 文字盤の外周に、待っている人の顔ピンを短い針の位置に表示。同じ時刻は人数バッジ付きで1本にまとめる。締め切りが近いピンは赤く点滅する。
- 針が合うと、該当するピン・注文票・並んでいる人が光る。注文票やピンをタップすると、正解の針を点線で表示する。正解を目にする回数を増やし、文字と盤面を対応づける。
- 外周の帯は「いま」から閉店までの残り時間。画面上部の空の帯に、朝から夜までの一日、太陽または月（いま）、各注文の位置を表示する。
- 注文票の下の線は、締め切りまでの残り時間。短くなると赤くなって震える。
- 午前・午後はトグルで選ばせず、針の位置（一日のどこか）から決まる。文字盤に ☀午前 / ☾午後 / あした を表示する。
- 列：入口から入って一列に並び、カウンター前から順に詰める。刻印すると注文票に「済」印が押され、並んでいる人が跳ねて退店し、音程が上がる。退店が終わってから後ろの人が一歩ずつ詰める。

## 試作コース

|コース|刻み|営業時間|1時間の実時間|注文の書き方|
|---|---|---|---|---|

|港のお昼どき|30分|午前9時〜午後7時|12秒|午前午後・半・◯時間後|
|洞窟の夕方便|15分|正午〜午後9時|14秒|午前午後・24時間・◯分後|
|真夜中の空便|5分|午後6時〜あした午前2時|16秒|全部・日付またぎ|

「ゆっくり／いそがしい」は、時間の流れ・来店間隔・締め切りまでの秒数をまとめて1.5倍／0.75倍にする。

## 検証メモ

一定間隔で「いちばん早いピン」か「人数がいちばん多いピン」を刻印するシミュレーション（長い針1周に0.8秒の手間を加算）の、届けられた割合。

|コース|2秒ごと|5秒ごと|7秒ごと（早い順／人数順）|
|---|---|---|---|
|森|100%|100%|100% / 94%|
|港|100%|100%|93% / 87%|
|洞窟|100%|96%|79% / 82%|
|夜便|100%|85%|63% / 74%|

速く捌く人は損をしない。ゆっくり遊ぶほど列が伸び、1便あたりの人数が自然に増える（2秒ごとで約1人、7秒ごとで約2.5人）。忙しいコースでは、人数の多い時刻を狙う方が届けられるようになる。

## 本編への組み込み（0.6.0）

- 36便：章ごとに刻み（60/30/15/5→1/5/5分）、開店時刻、1時間の実時間を決め、6便で一日を約60秒から約120秒へ延ばし、来店間隔を縮める。1章1〜2便は「午前◯時」だけ、3便目から「◯時間後」が混ざる。5章から24時間表記、6章は相対時刻が中心で日付をまたぐ。
- 星：届けた割合が5割未満は未クリア（星0）。記録は既存形式 `{stars,time,mistakes}` のまま保存し、`mistakes` に取りこぼし人数を入れる。旧ルールの星も比較して高い方を残す。
- エンドレス：閉店なし（午前6時開店）。12人届けるごとに時間と来店が6%速くなり（最大45%）、取りこぼし5人以上で店じまい。
- 再挑戦の補助は、♥6の「おてつだい」から「ゆっくりモード」（時間・来店・締め切りを1.4倍）に変更。
- 店の場面は `queue-places.webp`（左にカウンター）と `queue-residents.webp` を使い、入口（右）から一列に並ぶ。奥の人ほど小さく高く描く。
