# 一日便（ルール試作）

0.5 の「ラッシュ」を置き換える候補。試作ページは `/prototype/index.html`、ルール本体は `src/route.js`。本編にはまだ組み込まない。

## ねらい

- ラッシュの圧は残す。慌てる中で、文字の時刻と文字盤を反射的に結びつける。
- 圧をかける代わりに、捌けたときの快感をしっかり返す。
- 力技（いちばん早い注文から1件ずつ刻印）でもクリアできる。クリアした後で、まとめ便の効率化に頭が向く。
- 午前・午後と「◯時間後」を後付けの変則ルールにせず、最初からゲームの仕組みとして使う。

## ルール

- 1便＝お店の一日。針は開店時刻から始まり、時計が「今日の運行表」になる。
- **針は前にしか進まない。** 刻印するまでは自由に戻せる（ドラッグの行き過ぎは直せる）が、刻印した時刻（＝いま）より前には戻れない。
- 刻印すると、その時刻の注文を持つ人が、列の位置や書き方（午後2時半／14時30分／2時間半後）に関係なく全員まとめて配達される。
- 刻印した時刻より前を注文していた人は**乗り遅れ**（♥−1）。
- 列には定員がある。満員のときに来た人は帰ってしまう（♥−1）。一人ずつの待ち時間ゲージはない。
- 誰もいない時刻に刻印しても、時間は進まずコンボが切れるだけ。
- 一便を出す重さは軽く、飛行機の待ち時間や便数の上限はない。
- 来客は「いま」より後の時刻を、近い時間を中心に注文する。すでに待っている時刻を別の書き方で頼むことが多い（まとめ便の種）。
- 閉店が近づいて時刻の余裕がなくなると、注文は残りの時刻に集まる（閉店前の駆け込みラッシュ）。来客がなくなることはない。
- 相対時刻は、来店したときの「いま」（最後に刻印した時刻）が基準。注文票に受付時刻を表示する。
- まとめ便の得点は `100n + 50n(n−1)`。コンボ1回ごとに最大＋90%。

## 表示

- 操作するのは長い針だけ。文字盤のどこをなぞっても長い針が回り、短い針は時刻に合わせてついてくる（一周で1時間）。「時」が変わる瞬間に高い音。大きく進めるときは ±1時間 ボタン。

- 文字盤の外周に、待っている人の顔ピンを短い針の位置に表示。同じ時刻は人数バッジ付きで1本にまとめる。12時間以上先のピンは薄くする。
- 針が合うと、該当するピン・注文票・並んでいる人が光る。注文票やピンをタップすると、正解の針を点線で表示する。正解を目にする回数を増やし、文字と盤面を対応づける。
- 外周の帯は「いま」から閉店までの残り時間。画面上部の空の帯に、朝から夜までの一日と各注文の位置を表示する。
- 午前・午後はトグルで選ばせず、針の位置（一日のどこか）から決まる。文字盤に ☀午前 / ☾午後 / あした を表示する。
- 列：入口から入って一列に並び、カウンター前から順に詰める。刻印すると注文票に「済」印が押され、並んでいる人が跳ねて退店し、音程が上がる。退店が終わってから後ろの人が一歩ずつ詰める。

## 章の考え方（案）

章ごとに上げるのは、分の細かさ（正時→半→15分→5分→1分）、書き方の種類（24時間表記は後半）、営業時間の長さ、来店ペース。午前・午後と相対時刻は、1章から簡単な形で入っている。

|試作コース|刻み|営業時間|人数|注文の書き方|
|---|---|---|---|---|
|森の朝市|60分|午前7時〜午後7時|14|午前午後・◯時間後|
|港のお昼どき|30分|午前9時〜午後8時|20|午前午後・半・◯時間後|
|洞窟の夕方便|15分|正午〜午後9時|24|午前午後・24時間・◯分後|
|真夜中の空便|5分|午後6時〜あした午前2時|28|全部・日付またぎ|

## 検証メモ

`tests/route.test.mjs` の力技テストで、全コースが取りこぼしなしでクリアできることを確認。一定間隔で刻印するシミュレーションでは、ゆっくり遊ぶ人ほど列が伸び、1便あたりの人数が自然に増える（2秒ごと：1.0人、7秒ごと：約2人）。
